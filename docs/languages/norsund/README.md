# Norsund

**Norsund** ("north-tongue") is the common language of Thiolden. Vilnayan villagers, the Vilkyren on the hunt, the Sundwanderen in the taverns and the Seven Lights of Auristar all speak it. It is the second language of most of Thiolden's races.

```
Kjal, thiol-en! Ma star-en kjold-a dun.
drink.IMP brave-PL.AN OPT star-PL.AN guard-INF 2PL.OBJ
"Drink, brave ones! May the stars keep you."
```

Version **1.0.0** (2026-11-19). See the [CHANGELOG](CHANGELOG.md).

## What it's like

- **Norse bones.**
  - Short words, clusters like *kj-*, *fj-* and *thi-*.
  - Stress always on the first syllable.
  - The verb always second in a statement.
  - "The" as an ending (*murin* "the wall").
  - Verbs that change their vowel in the past (*dola*, *dul*).
- **A Kedre layer.** The Vairean conquest left words for walls, canals, markets and towers, much as the Normans left French in English.
- **A star-soaked culture in the grammar.**
  - Speakers mark how they know things: *sa* (I saw it), *sund* (so it is sung), *stari* (so the stars say).
  - In Auristar, stars are living beings.
  - Pronouns mark living vs non-living, not sex.
- **Real history.** Every canon name has an etymology, and the sound changes from Proto-Valian can be replayed by the tools.

## Quick start with the tools

You need Node.js 20 or newer.

```sh
cd tools && npm install

node cli.mjs en tavern                         # English → Norsund words
node cli.mjs lookup kjoldade                   # a word or any of its forms
node cli.mjs inflect kjolda                    # every form of a word
node cli.mjs gloss "Fjol starin lyser run ne." # word-by-word gloss
node cli.mjs translate "The stars guard the city."
node cli.mjs packet "Kjal, thiolen!"           # pronunciation packet for actors
node cli.mjs name place --count 5              # names that mean something
node cli.mjs render lysrit "Auristar" --out auristar.svg
node cli.mjs validate                          # check the records before a pull request
```

**The workbench** puts all of this in a browser (dictionary, translator, script writer, name forge, sound lab). A hosted copy is at https://claude.ai/artifact/CA2a7yRiUdNU4zfVPDGknV (private until the owner shares it), or run it locally:

```sh
cd tools && npx serve web
```

See [tools/README.md](../../../tools/README.md) and [tools/web/README.md](../../../tools/web/README.md).
