# Norsund phrasebook

Ready-made phrases for writers, players, game designers and voice actors. The source, with full glosses, is [records/languages/norsund/texts/04-phrasebook.yaml](../../../records/languages/norsund/texts/04-phrasebook.yaml), and this page is generated from it. The "Say it" column comes from the engine (`node tools/cli.mjs respell`); stress the first syllable of each word.

**Norsund has no word for "please".** Ask politely with *ma* "may" and an infinitive: *Ma dy jova om aul* means "May you give me ale", that is, "Some ale, please". In Auristar, also use the plural *dyn* to anyone of rank.
